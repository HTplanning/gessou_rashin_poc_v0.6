# 月相羅針 計算PoC v0.6｜入力UI・現在値改善

春華プロジェクトの「月相羅針 Web計算サービス」を技術検証するための、小規模な Flask Web アプリです。

## 重要

この PoC は、**月相羅針の正式占術仕様を確定するものではありません。**

現在の P01〜P08 は、360°を45°ずつ8等分し、標準的な月相名称とPoC用説明文章を割り当てた技術確認用の仮仕様です。春華独自の正式な月相羅針の ID・名称・角度範囲・境界条件・説明文・特徴・進み方が確定したら、`phase_classifier.py` の定義を差し替える前提です。

また、v0.2で追加しv0.6でも維持している出生時間不明時の扱いも、**PoCの技術検証仕様であり、春華独自の正式な出生時間不明時ルールではありません。**

## 実装範囲

### 出生時間が分かる場合

1. 生年月日・出生時間・出生地を入力
2. 日本国内として `Asia/Tokyo` を使用
3. 出生時刻を UTC へ変換
4. pyswisseph で地心・トロピカルの太陽黄経・月黄経を計算
5. `(moon_longitude - sun_longitude) % 360.0` で角度差を算出
6. 技術確認用の標準月相8分類を1つ判定
7. ブラウザ画面へ結果を表示

### 出生時間が分からない場合

出生時間が未入力の場合、特定の仮時刻を使って1分類に決めるのではなく、その出生日の範囲内で月相分類が変化する可能性を確認します。

- 対象時刻：`00:00:00` ～ `23:59:59`（Asia/Tokyo）
- PoC v0.6で維持する基本サンプリング：30分刻み＋`23:59:59`
- サンプル間は角度差を連続値として追跡し、45°区分を通過した場合は候補へ含めます
- 360°→0°のラップアラウンドも連続角として扱います

一日中同じ分類の場合：

- `classification_status == "stable"`
- 1つの候補を表示します

一日の途中で分類境界をまたぐ場合：

- `classification_status == "ambiguous"`
- 複数候補を表示します
- 1つに確定しません

この方式は、**春華独自の正式な出生時間不明時ルールではなく、技術PoCの暫定方式**です。将来正式ルールが決まった場合に差し替えられるよう、天体計算と分類処理を分離しています。

## v0.6 の変更点

今回の v0.6 では、計算ロジック・8分類・出生時間不明時の候補判定は変更せず、入力UIだけを最小修正しています。

- 生年月日・出生時間・出生地の入力欄を同一高さに統一
- 生年月日と出生時間の上端位置をそろえたまま維持
- iPad/Safari の date/time ネイティブ表示で高さが膨らむ場合を想定し、block-size も固定
- `style.css?v=0.6` としてCSSキャッシュの影響を避ける
- 生年月日が空欄で入力画面を開くと、端末ローカルの現在年月日を現在値として設定
- 出生時間が空欄で入力画面を開くと、端末ローカルの現在時刻（分単位）を現在値として設定
- 空欄から開いた入力画面で値を変更せず「✓」で確定しても、その現在値が入力欄へ採用される
- v0.5の「リセット後は前回計算値へ戻さず未入力にする」仕様を維持

## v0.5 の変更点

今回の v0.5 では、計算ロジック・8分類・出生時間不明時の候補判定は変更せず、入力画面だけを最小修正しています。

- 生年月日と出生時間の入力欄が、iPad/Safariでも同じ上端・同じ高さに揃いやすいようCSSを調整
- 計算後も直前の入力内容は画面上に表示する
- ただしHTMLの既定値（default value）は空欄のままにし、iPad/Safari等の入力UIで「リセット」を選んだときに前回計算値へ戻らず未入力状態へ戻せるよう変更
- 将来通常のフォーム用リセットボタンを追加した場合も、生年月日・出生時間・出生地を空欄にするリセット処理を追加

この変更は入力UIの挙動改善であり、天体計算、角度差計算、月相8分類、出生時間不明判定の仕様変更ではありません。

## 必要環境

- Python 3.9 以上を推奨
- pip

## インストール

プロジェクトフォルダへ移動して実行します。

```bash
pip install -r requirements.txt
```

## 起動

```bash
python app.py
```

ブラウザで次を開きます。

```text
http://127.0.0.1:5000
```

## GitHub Codespaces での起動

Codespaces の Terminal で次を実行します。

```bash
pip install -r requirements.txt
python app.py
```

Flask は `0.0.0.0:5000` で待ち受けます。Codespaces の **PORTS** タブで **5000** 番ポートを見つけ、**Open in Browser** を選択してください。

## モジュール分離方針

- `astronomy.py`：現地時刻→UTC→ユリウス日→太陽・月黄経→角度差、出生時間不明時の日内複数時刻計算
- `phase_classifier.py`：1角度の8分類、複数角度から候補分類を求める処理
- `location_master.py`：出生地→タイムゾーン（将来は緯度・経度・歴史的タイムゾーンへ拡張）
- `app.py`：入力、検証、各モジュール呼び出し、結果・エラー表示

これにより、正式な月相羅針仕様や出生時間不明時ルールが決まった際に、天体計算ロジックを作り直さず分類・候補判定ロジックを更新できます。

## 天体暦について

コードは `pyswisseph` に対して Swiss Ephemeris モードを要求します。外部の Swiss Ephemeris 天体暦データファイルが環境に存在しない場合、ライブラリが Moshier モードへフォールバックすることがあります。画面には実際に使用されたモードを表示します。

PoCの再現性をより厳密に固定する段階では、使用する天体暦データファイル、バージョン、配置方法まで固定して管理してください。
